# Sojib Ahmed Portfolio

A world-class, premium MERN Stack Developer Portfolio website built with React, TypeScript, Tailwind CSS, Node.js, Express.js, and MongoDB.

## Features

- Modern, cinematic dark theme UI/UX
- AI-powered chatbot (Gemini API)
- Responsive design (Mobile, Tablet, Laptop, Desktop)
- Dark/Light mode toggle
- Admin dashboard
- Contact form with email notifications
- GitHub integration
- Project case studies
- Skills showcase with real icons
- Certificate section
- Smooth animations (Framer Motion, GSAP)

## Tech Stack

### Frontend
- React.js + TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- Vite

### Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication
- Nodemailer

## Deployment

- **Frontend:** Vercel
- **Backend:** Render
- **Database:** MongoDB Atlas
